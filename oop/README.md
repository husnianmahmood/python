## 📖 Overview

The `oop/` directory represents the second major milestone in this repository. Shifting away from procedural scripts, this track focuses on structuring Python applications around real-world modeling, domain abstraction, clean interfaces, and robust application state management.

The focus here is not just knowing OOP syntax, but understanding **how to write clean, maintainable, and extensible Python code**.

---

## 💡 Core Concepts Covered

This module progressively introduces and applies the primary paradigms of Object-Oriented Software Engineering:

- **Classes & Objects** — Constructing custom data types, instantiating stateful objects, and utilizing `__init__` constructors.
- **Encapsulation & Access Modifiers** — Protecting internal state with private attributes (`__attr`), property getters, setters, and state validation logic.
- **Abstraction & Interfaces** — Enforcing structural contracts using Python’s Abstract Base Classes (`abc.ABC`, `@abstractmethod`).
- **Inheritance & Method Overriding** — Extending base functionality, reusing behavior, and customizing subclass operations cleanly.
- **Dynamic Runtime Polymorphism** — Decoupling caller logic from concrete implementations by treating varied subclass types through unified base interface signatures.
- **File Handling & Persistence** — Exporting structured runtime state into local storage formats.
